# Beam Designer

Beam Designer is a Python/Tkinter desktop app for analyzing simply supported beams and cantilevers. Define spans, loads, materials, and sections to view shear, moment, and deflection diagrams with bending and deflection checks. Designs can be saved/opened, and results can be exported as CSV or a PDF calculation sheet.

## Install

```sh
python3 -m pip install -r requirements.txt
```

Required packages: NumPy and Matplotlib. Tkinter is included with the standard Python installation on macOS and Windows.

## Start

```sh
python3 app.py
```
